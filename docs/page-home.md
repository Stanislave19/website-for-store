## 2. Головний банер (hero)

- **На всю ширину**, висота ~520px, тло **racing green `#14361F`**
- Дві колонки: текст (~50%) + фото (~45%)

**Ліворуч (текст):**
- Заголовок: Fraunces, **48px**, вага 500, колір **cream `#FAF8F3`** — «Годинники, що переживуть моду»
- Підзаголовок: Work Sans, **17px**, колір **`#CFE0D2`** (світло-зелений), 2 рядки — «Ми обираємо моделі, які залишаються актуальними десятиліттями. Класика, що передається у спадок.»
- Кнопка: тло **brass `#B8894B`**, текст білий, Work Sans 15px/500, кути 3px, padding ~16px 28px — «Перейти до каталогу»

**Праворуч:** велике фото годинника (заглушка), межа ледь світліша за фон

> Латунна кнопка на зеленому — головний акцент сторінки. Саме тут латунь працює найсильніше.

- Іконка (Lucide, **brass**, 20px) + текст (Work Sans, 14px, ink)
- «Оригінальний товар» (галочка в колі)
- «Гарантія 24 місяці» (щит)
- «Доставка Новою Поштою» (вантажівка)
- «Консультація менеджера» (чат)

## 4. Секція «Оберіть свій стиль» (категорії)

- Заголовок: Fraunces, **28px**, вага 500, ink
- **Три картки** в рядок (білі, межа 1px edge, кути 3px), gap ~28px
- Кожна картка:
  - Фото-заглушка зверху (квадратна або 4:3)
  - Під фото: назва (Fraunces, **20px**, 500, ink) + кількість моделей (Work Sans, 13px, **brass**)
- Категорії: **Чоловічі (312 моделей) · Жіночі (201) · Унісекс (58)**
- Ховер: межа стає brass

## Дані → API

- **Популярні моделі:** `GET /api/products?sort=newest&page_size=4` (рейтингів у MVP немає — секція показує добірку новинок або вручну позначені товари)
- **Нові надходження:** `GET /api/products?sort=newest&page_size=4&offset=4`
- **Категорії:** `GET /api/categories` + лічильники товарів
- **Знаки довіри, слоган, банер:** статичні (у коді або `settings`)

---

## Мобільна версія

- **Банер:** колонки складаються — текст зверху, фото знизу. Заголовок ~32px
- **Знаки довіри:** 2×2 замість рядка
- **Категорії:** одна колонка, картки одна під одною
- **Сітки товарів:** 2 колонки
- **«Про нас»:** фото зверху, текст під ним

---

## Що НЕ переносити

- HTML із Claude Design (`.dc.html`) — інший стек, переписувати в React + Tailwind
