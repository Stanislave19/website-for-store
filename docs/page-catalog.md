# Сторінка каталогу — специфікація

> Еталон верстки. Візуальний референс: `docs/design/catalog-1.png`, `catalog-2.png`, `catalog-3.png`. Точні значення нижче витягнуті з готового макета. Джерело правди для палітри й шрифтів — `design-system.md`.

## Шрифти (Google Fonts)

```
https://fonts.googleapis.com/css2?family=Fraunces:wght@400;500&family=Work+Sans:wght@400;500&display=swap
```

- **Fraunces** (serif) — заголовки, навігація, назви товарів
- **Work Sans** (sans) — ціни, кнопки, фільтри, описи, весь інтерфейс
- Ваги: тільки 400 і 500

## Палітра (підтверджена макетом)

| Змінна | HEX | Використання |
|---|---|---|
| cream | `#FAF8F3` | фон сторінки |
| ink | `#1B1B1B` | текст, заголовки |
| racing | `#14361F` | кнопки, ціни, футер, лого, активні теги |
| brass | `#B8894B` | лічильники, акценти, лого у футері, ховер |
| leather | `#6B4A34` | вторинний текст, описи |
| edge | `#E2DACE` | межі, рамки |
| white | `#FFFFFF` | картки товару, поля вводу |
| footerText | `#CFE0D2` | приглушений текст на зеленому футері |

## 1. Шапка (header)

- Тло: cream, знизу межа 1px edge
- Вертикальні відступи: 28px
- **Лого зліва:** круг 48px, тло racing, усередині кремовий текст «LEROM» + тонка лінія + «WATCH CO.» (дрібно). Праворуч від круга — напис «LEROM» (Fraunces, 22px, 500, ink)
- **Навігація по центру:** Каталог · Про нас · Гарантія · Контакти
  - Fraunces, 17px, вага 500, колір ink
  - проміжок між пунктами 36px
  - ховер: колір brass + тонка лінія знизу
- **Іконки справа** (Lucide, 22px, проміжок 22px): пошук · сердечко (wishlist) · кошик · користувач (кабінет)

## 2. Заголовок сторінки

- «Наручні годинники» — Fraunces, 34px, вага 500, ink
- Поруч (baseline): «571 моделей» — Work Sans, 15px, brass

## 3. Панель фільтрів (ліворуч, ~260px)

Порядок груп: **Категорія · Стать · Бренд · Ціна · Тип механізму** → «Більше фільтрів» → «Скинути»

**Заголовок групи:** Fraunces, 15px, 500, ink

**Теги (не чекбокси!):** обтікають у кілька рядків, gap 8px
- *Неактивний:* тло white, межа 1px edge, текст ink (Work Sans 13px), кути 3px, padding 7px/14px. Лічильник у дужках кольором brass: «Класичні (214)»
- *Активний:* тло racing, текст cream, хрестик ✕ праворуч (знімає фільтр)
- *Ховер неактивного:* межа стає brass

**Фільтр ціни:**
- Два поля вводу в рядок (white, межа edge, кути 3px, текст по центру), між ними тире
- Під ними повзунок: доріжка racing (3px), дві білі круглі ручки 22px з межею racing
- Під повзунком підписи по краях: «1 550 грн» / «19 275 грн» (Work Sans, 12px, leather)

**Кнопки внизу:**
- «Більше фільтрів» — контурна, межа edge, на всю ширину панелі
- «Скинути» — текстова, колір brass

## 4. Сортування

Над сіткою праворуч, у рядок:
- «Сортування:» — Work Sans, 14px, leather
- Випадаючий список — Work Sans, 14px, ink, без рамки, стрілка вниз
- Значення: **Новинки** (за замовчуванням) · Спочатку дешевші · Спочатку дорожчі

> **Важливо:** сортування «За рейтингом» НЕ використовувати — рейтингів і відгуків у MVP немає (ні в схемі, ні в API). Дозволені значення `sort`: `newest`, `price_asc`, `price_desc`.

## 5. Сітка товарів

**4 колонки** на десктопі, gap ~28px.

**Картка товару:**
- Фото: квадрат (aspect-ratio 1/1), тло white, межа 1px edge
- **Сердечко (wishlist):** білий круг 30px, межа edge, у правому нижньому куті фото
- **Крапки-індикатори:** на фото знизу по центру, 5 крапок 6px. Активна — racing, решта — edge
- **Перегортання фото при наведенні:** курсор рухається по фото зліва направо → фото змінюються (як у Casio), крапки слідують
- **Назва:** Fraunces, 22px, 500, ink
- **Опис:** Work Sans, 14px, leather, обрізаний (2-3 рядки)
- **Ціна:** Work Sans, 18px, 500
  - звичайна — racing
  - **зі знижкою — `#8B2635` (винний)**, поруч стара перекреслена (leather, 13px)
- **Кнопка «Купити»:** тло racing, текст cream, Work Sans 14px/500, кути 3px, padding 12px 24px

## 6. Пагінація

Унизу сітки, по центру: ‹ 1 2 3 … 12 ›
- Активна: тло racing, текст cream, кути 3px
- Неактивні: прозорі, текст ink, межа edge
- Ховер: brass

## 7. Футер

- Тло: racing
- **Лого:** круг з обведенням brass, кремовий текст усередині. Праворуч — «LEROM» (Fraunces, 22px, cream)
- **Слоган:** «Годинники для тих, хто цінує стриману впевненість.» (Work Sans, 14px, footerText)
- **Соцмережі:** круглі контурні іконки (Instagram, Facebook), межа світла
- **Колонка «Каталог»:** посилання Каталог · Про нас · Гарантія · Контакти (Work Sans, footerText)
- **Колонка «Контакти»:** телефон, email (brass), адреса
- **Колонка «Зв'язатися»:** контурні кнопки Telegram, Viber (межа світла, кути 3px)
- **Знизу:** тонка лінія-роздільник + копірайт «© 2026 LEROM Watch Co. Усі права захищено.» (12px, приглушено)

## Що НЕ переносити з макета

- HTML із Claude Design (`.dc.html`) — це інший стек (`<sc-for>`, `<x-dc>`). Переписувати в React + Tailwind, не копіювати.
- Заглушки «фото годинника» — замінити на реальні зображення з бази.
- Тестові назви товарів (Heritage 1922, Atelier Slim) — це приклади, дані йдуть з API.

## Мобільна версія (обов'язково)

- Сітка: 2 колонки
- Фільтри: шторка знизу, не бічна панель
- Фото: свайп замість наведення
- Шапка: компактна, меню-бургер
- Кнопки: мін. 44px висота
