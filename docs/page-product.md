Ті самі, що в каталозі: **Fraunces** (serif) + **Work Sans** (sans), ваги 400/500.

## Палітра

Та сама, що в каталозі. Додатково використовується:
| Змінна | HEX | Використання |
|---|---|---|
| surfaceSoft | `#F3F0E8` | легкі підкладки, заглушки фото |
| footerMuted | `#3C5C46` | приглушені елементи на зеленому |

## Структура сторінки

### 1. Шапка
Ідентична каталогу (див. `page-catalog.md`).

### 2. Хлібні крихти
- Work Sans, 13px
- Посилання — колір leather `#6B4A34`, поточна сторінка — ink
- Розділювачі «/» — edge
- Приклад: Головна / Каталог / **Класичні** / Heritage 1922

> **Важливо:** третій рівень — це **категорія товару** (`products.category_id` → `categories.name`: Класичні, Спортивні, Мінімалістичні, Скелетони), а НЕ стать. «Чоловічі/Жіночі» — це поле `gender` (enum), воно не має ієрархії й не може бути хлібною крихтою. Якщо категорія має батька (`parent_id`), показувати ланцюжок рекурсивно.

### 3. Верхній блок — дві колонки

#### Ліва колонка (~55%) — галерея

- **Головне фото:** квадратне (aspect-ratio 1/1), тло white, межа 1px edge
- **Мініатюри під фото:** 5 штук у рядок, квадратні (~96px), gap 12px
  - Активна: межа 2px brass `#B8894B`
  - Неактивні: межа 1px edge
  - Клік змінює головне фото
- Відступ між головним фото й мініатюрами — невеликий (~16px), не відривати їх

#### Права колонка (~45%) — інформація

Порядок згори вниз:

1. **Бренд:** Work Sans, 13px, brass — «Lerom Heritage»
2. **Назва товару:** Fraunces, **34px**, вага 500, ink — «Heritage 1922»
3. **Артикул:** Work Sans, 13px, leather — «Арт. LR-1922-BR»
4. **Ціна:** Work Sans, **28px**, вага 500
   - звичайна — racing `#14361F`
   - **зі знижкою — `#8B2635` (винний)**, поруч стара перекреслена (leather, 16px)
5. **Короткий опис:** Work Sans, 15px, leather, line-height 1.6, 2-3 рядки
6. **Кнопки в рядок:**
   - «Купити» — тло racing, текст cream, Work Sans 15px/500, кути 3px, ширша (~65%)
   - «В обране» — контурна, межа edge, іконка-сердечко + текст, кути 3px
7. **Знаки довіри** — три штуки, іконка (Lucide, 20px, brass) + текст (Work Sans, 13px, leather):
   - «Гарантія 24 місяці» (щит)
   - «Оригінальний товар» (галочка в колі)
   - «Доставка Новою Поштою» (вантажівка)
8. **Блок консультації:** межа 1px edge, кути 3px, padding
   - Заголовок «Потрібна консультація?» — Fraunces, 16px
   - Кнопки Telegram і Viber — контурні, межа edge, Work Sans 14px, кути 3px

## Дані з API

Сторінка отримує дані через `GET /api/products/{slug}`:
- назва, slug, опис, ціна, old_price, артикул (sku)
- бренд, категорія, стать, тип механізму
- усі EAV-атрибути → секція «Характеристики»
- `warranty_months` → блок «Гарантія»
- `package_contents` → блок «Комплектація»
- усі фото (product_images, за `position`) → галерея
- схожі моделі — окремий запит (та сама категорія або бренд)

## Мобільна версія

- Колонки складаються в одну: спершу галерея, потім інформація
- Галерея — свайп по фото, мініатюри під ним
- Характеристики — одна колонка замість двох
- Кнопки «Купити» / «В обране» — на всю ширину, одна під одною
- Схожі моделі — 2 колонки

## Що НЕ переносити

- HTML із Claude Design (`.dc.html`) — інший стек, переписувати в React + Tailwind
- Заглушки «фото годинника» — замінити реальними зображеннями
- Тестові дані (Heritage 1922, ціни) — приклади, дані йдуть з API
