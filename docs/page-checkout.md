# Сторінка оформлення замовлення — специфікація

> Еталон верстки. Візуальний референс: `docs/design/checkout-1.png` … `checkout-3.png`. Точні значення витягнуті з макета. Джерело правди для палітри й шрифтів — `design-system.md`.

> **Важливо:** у MVP оплати НЕМАЄ. Це заявка. Кнопка — «Оформити замовлення», не «Оплатити». Після відправки менеджер зв'язується з клієнтом.

## Шрифти й палітра

Ті самі, що в каталозі й картці товару (Fraunces + Work Sans, Racing Green & Brass).

---

## Структура

**Хлібні крихти:** Головна / Кошик / Оформлення (Work Sans 13px, leather)

**Заголовок:** «Оформлення замовлення» — Fraunces, **34px**, вага 500, ink

**Дві колонки:** форма (~60%) + підсумок (~40%), gap ~40px

---

## ЛІВА КОЛОНКА — форма

Три білі блоки (межа 1px edge, кути 3px, padding ~28px, проміжок між блоками ~24px).

**Загальний стиль полів:**
- Тло white, межа 1px edge, кути 3px, висота **44px**
- Текст: Work Sans, 15px, ink
- Плейсхолдер: leather
- Підпис над полем: Work Sans, 13px, leather. Обов'язкові позначені зірочкою `*` кольором brass
- Фокус: межа racing `#14361F`

### Блок 1 — «Контактні дані»
Заголовок: Fraunces, **20px**, 500

- **Ім'я** * — плейсхолдер «Ваше ім'я»
- **Прізвище** * — плейсхолдер «Ваше прізвище». Підказка під полем (Work Sans 12px, leather): «Потрібне для оформлення посилки Новою Поштою»
- **Телефон** * — поле з окремим блоком-префіксом «+380» зліва (межа edge, тло white), далі поле з плейсхолдером «00 000 0000»

### Блок 2 — «Доставка»
Заголовок: Fraunces, 20px, 500

- **Способи доставки** — 4 картки в сітці 2×2, gap 12px, кожна з радіо-кнопкою:
  - *Обрана* (Нова Пошта за замовчуванням): межа 2px racing, тло ледь зеленувате, радіо заповнене racing
  - *Необрані*: межа 1px edge, тло white
  - Варіанти: **Нова Пошта · Укрпошта · Кур'єр · Самовивіз**
- **Місто** — поле, плейсхолдер «Ваше місто» (показувати для НП / Укрпошти / кур'єра)
- **Відділення** — поле, плейсхолдер «Номер або адреса відділення» (тільки для Нової Пошти)
  - *Виправлення:* НЕ дублювати той самий текст підказкою під полем — досить плейсхолдера

### Блок 3 — «Зв'язок»
Заголовок: Fraunces, 20px, 500

- **Зручний спосіб зв'язку** — три радіо в рядок: **Дзвінок** (обрано) · Telegram · Viber
- **Коментар до замовлення** — textarea, 3 рядки, плейсхолдер «Необов'язково»

---

## ПРАВА КОЛОНКА — підсумок замовлення

Білий блок (межа edge, кути 3px, padding ~28px), **липкий при прокрутці** (sticky).

- **Заголовок:** «Ваше замовлення» — Fraunces, **22px**, 500

- **Список товарів:**
  - Мініатюра фото 72px (квадрат, межа edge)
  - Праворуч: назва (Fraunces 15px, 500), артикул (Work Sans 12px, leather), ціна (Work Sans 15px, 500)
  - Зі знижкою: ціна винним `#8B2635` + стара перекреслена (leather, 13px)
  - Роздільник між товарами — лінія 1px edge

- **Промокод:** поле вводу + кнопка «Застосувати» (контурна, межа edge, Work Sans 14px) в один рядок

- **Роздільник** (лінія edge)

- **Підсумки** (Work Sans, 14px):
  - «Товари» → сума (ink)
  - «Знижка» → −2 000 ₴ (**винним** `#8B2635`)
  - **«Разом»** → Work Sans **22px**, вага 500, **racing green**

- **Кнопка «Оформити замовлення»:** тло racing, текст cream, Work Sans 16px/500, на всю ширину, висота ~52px, кути 3px

- **Під кнопкою** (Work Sans 12px, leather, по центру): «Менеджер зв'яжеться з вами найближчим часом для підтвердження»

## Валідація (для реалізації)

- **Ім'я, Прізвище, Телефон** — обов'язкові
- **Телефон** — формат +380, перевірка на клієнті й на сервері
- **Місто, Відділення** — обов'язкові, якщо обрано Нову Пошту / Укрпошту
- Помилка поля: межа стає `#B3261E`, під полем текст помилки (Work Sans 12px, `#B3261E`)

## Дані → API

Форма надсилає `POST /api/orders`:
```
{
  items: [{product_id, quantity}],
  first_name, last_name, phone,
  delivery_method: nova_poshta | ukrposhta | courier | pickup,
  city, np_office,
  contact_method: call | telegram | viber,
  comment,
  promo_code (опційно)
}
```
Промокод перевіряється окремо: `POST /api/cart/validate-promo`

Після успіху → редірект на екран-підтвердження з номером заявки.

## Мобільна версія

- Колонки складаються: спершу форма, підсумок унизу (або липкий блок із сумою + кнопкою знизу екрана)
- Картки доставки — одна колонка
- Поля — на всю ширину, висота мін. 46px
- Кнопка «Оформити» — на всю ширину, фіксована знизу
