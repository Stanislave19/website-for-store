# Сторінка кошика — специфікація

> Еталон верстки. Візуальний референс: `docs/design/cart-1.png` … `cart-3.png`. Точні значення витягнуті з макета. Джерело правди для палітри й шрифтів — `design-system.md`.

> **Важливо:** кошик живе **у браузері (localStorage)**, не в базі. Бекенд лише перевіряє промокод (`POST /api/cart/validate-promo`).

## Шрифти й палітра

Ті самі (Fraunces + Work Sans, Racing Green & Brass).

---

## Структура

**Хлібні крихти:** Головна / Кошик (Work Sans 13px, leather)

**Заголовок:** «Кошик» — Fraunces, **34px**, 500, ink. Поруч (baseline): «3 товари» — Work Sans 15px, **brass**

**Дві колонки:** список товарів (~65%) + підсумок (~35%), gap ~40px

---

## ЛІВА КОЛОНКА — список товарів

Білий блок (межа 1px edge, кути 3px). Позиції розділені тонкими лініями edge.

**Кожна позиція** (padding ~24px, елементи в рядок):

- **Фото:** квадрат ~110px, тло white, межа edge
- **Інформація:**
  - Назва — Fraunces, **20px**, 500, ink (клікабельна → картка товару)
  - Артикул — Work Sans, 12px, leather
  - Короткі характеристики — Work Sans, 13px, leather (напр. «Сталь, шкіряний ремінець»)
- **Кількість:** контрол «−» [число] «+»
  - Кнопки: квадратні ~32px, контурні (межа edge), кути 3px
  - Число: Work Sans 15px, 500
  - Ховер кнопок: межа стає brass
- **Ціна:** Work Sans, **18px**, 500, racing green
  - Зі знижкою: ціна **винним `#8B2635`**, під нею стара перекреслена (leather, 13px)
- **Видалити:** іконка кошика (Lucide, 18px, leather) у правому верхньому куті позиції. Ховер — `#B3261E` (помилка/видалення)

Під блоком: **«← Продовжити покупки»** — Work Sans 14px, brass

---

## ПРАВА КОЛОНКА — підсумок

Білий блок (межа edge, кути 3px, padding ~28px), **липкий при прокрутці** (sticky).

- **Заголовок «Підсумок»** — Fraunces, **22px**, 500
- **Промокод:** поле вводу + кнопка «Застосувати» (контурна, межа edge, Work Sans 14px) в рядок
- **Роздільник** (лінія edge)
- **Розкладка** (Work Sans, 14px):
  - «Товари (3)» → сума (ink)
  - «Знижка» → −2 000 ₴ (**винним `#8B2635`**)
  - «Доставка» → «За тарифами перевізника» (leather, дрібно)
- **Роздільник**
- **«Разом»** → Work Sans, **24px**, 500, **racing green**
- **Кнопка «Оформити замовлення»** — тло racing, текст cream, Work Sans 16px/500, на всю ширину, висота ~52px, кути 3px

## Порожній стан

Показувати замість обох колонок, коли кошик порожній:

- По центру, у білому блоці (межа edge, кути 3px)
- Іконка кошика (Lucide, 48px, edge)
- Заголовок «Кошик порожній» — Fraunces, **24px**, ink
- Текст «Перегляньте каталог і оберіть свій годинник» — Work Sans 15px, leather
- Кнопка «Перейти до каталогу» — тло racing, текст cream, кути 3px

---

## Логіка (для реалізації)

- Кошик зберігається в **localStorage** (хук `useCart`), не в базі
- Зміна кількості → перерахунок суми на клієнті
- Видалення позиції → оновлення списку й суми
- **Промокод:** `POST /api/cart/validate-promo` з `{code, cart_total}` → повертає тип і розмір знижки або помилку
- Помилка промокоду: текст під полем (Work Sans 12px, `#B3261E`)
- «Оформити замовлення» → перехід на `/checkout` з даними кошика
- Ціни беруться з API при завантаженні (щоб не показувати застарілі)

## Мобільна версія

- Колонки складаються: список зверху, підсумок унизу
- Позиція товару: фото зліва, інфо праворуч, кількість і ціна під ними
- Кнопка «Оформити» — на всю ширину, можна зафіксувати знизу екрана
- Кнопки «−»/«+» — мін. 40px (для пальця)
